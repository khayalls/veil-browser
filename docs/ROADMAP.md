# Roadmap

The goal is a restrained native macOS workflow centered on Spaces, sidebar organization, shortcuts and gestures.

Before daily-use readiness: complete Performance native QA, physical gesture/drag/hover acceptance, visual/accessibility combinations, authenticated-site compatibility, long browsing/soak tests, compositor/launch traces and battery energy measurements. Review CEF security updates and define an update process.

Later: evaluate Chrome extensions and their security surface, protected media within upstream licensing constraints, and a project-wide licensing/distribution policy.

VEIL has no autonomous AI process rewriting its executable. QA and bug fixing are development workflows; runtime optimization uses explicit tab/resource policies.
